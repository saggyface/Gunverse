# Asset Intake

CC0 model sourcing for Gun Verse. Poly Pizza is the automated source; Kenney,
Quaternius, and Poly Haven remain approved manual sources.

## API key

The pipeline reads the Poly Pizza key from `POLY_PIZZA_API_KEY`, or from:

`%USERPROFILE%\.config\gunverse\poly-pizza.key`

Never place the key in this project. Do not print it or commit it.

## Commands

Search only CC0, non-animated models up to 2,000 triangles:

```powershell
.\Tools\AssetIntake\asset-intake.ps1 search "milk carton" -MaxTriangles 2000 -Json
```

Poly Pizza occasionally returns a server error for very broad or empty queries.
Use a shorter keyword such as `can`, `bottle`, or `bread`, or inspect a known
model ID directly.

Inspect a known Poly Pizza model ID:

```powershell
.\Tools\AssetIntake\asset-intake.ps1 inspect T2QjC2ZQya -Json
```

Download a CC0 model into staging and `Assets/_GunVerse/Models/ThirdParty/PolyPizza`:

```powershell
.\Tools\AssetIntake\asset-intake.ps1 download T2QjC2ZQya -MaxTriangles 2000 -Json
```

Every download is validated as a GLB, hashed, and recorded in
`asset-manifest.json`. Staging files are not part of the Unity project import.

## Model-backed pickup prefabs

1. Download the model.
2. Add an entry to `item-models.json`.
3. Run `GunVerse.EditorTools.ModelPickupPrefabBuilder.ApplyConfiguredModels()`.
4. Run `GunVerse.EditorTools.GroceryStoreSetupBuilder.Build()` to rebuild item
   placement and network prefab registration.

`item-models.json` controls target height/size, per-part material colors,
projectile scale, and labels. The model is centered, scaled, and given a root
BoxCollider automatically. Label textures are generated by:

```powershell
.\Tools\AssetIntake\generate-item-labels.ps1
```
